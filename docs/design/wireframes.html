How It Works
Simple 3-step process to recover lost items
1
Report Your Lost Item
Post what you've lost with a clear description. Add photos if possible. Your post is visible to the entire campus community.
2
Community Helps You Find It

3

Message the finder directly via Messenger. Arrange a safe meetup location on campus. Mark the item as found once recovered!

Be a Good
Campus Citizen
This app works because students help each other. Here's how you can contribute:
✓
Report honestly
Only post items you've actually lost. Provide accurate descriptions to help finders identify your item.
✓
Help others find their items
If you find something, submit a claim with photo proof. Leave helpful tips if you saw an item someone is looking for.

Build trust
Respond to messages promptly. Update your posts when items are found. Be respectful in all communications.

Phase 1 vs Phase 2
ℹ️
PHASE 1 (MCO 1): Item Detail screen shows only: Photo, Title, Description, Reporter info, Status badge, "Mark as Found" button (for item owner). No communication features. Users can browse and view items offline, but cannot claim or send tips.

PHASE 2 (MCO 2): Adds cloud-based communication: "I Found This" claims with photo proof, Public Tips thread, Reporter replies, Messenger integration. Requires internet and sync.
Action bar (⑨⑩)
9
Sticky bottom bar — Reporter only "Mark as Found" as a full-width primary button. ⋮ overflow button for Edit / Delete / Report. Visible only to the item's owner.
10
Delete Item option In overflow menu. Shows confirmation dialog before permanently deleting. Once deleted, item is removed from database and cannot be recovered. Edit allows changing title/description. Report flags inappropriate content to admin.
Messenger Integration (Phone 2)
→
💬 Message on Messenger button After Reporter approves claim, button opens Facebook Messenger app (or WhatsApp/Telegram based on user preference). Reporter adds messenger username during registration. No in-app chat needed - uses familiar external messaging app.
→
Chip/Card Grid in Messenger Users can still coordinate meetup locations within Messenger chat. Location chips show: Security Office (⭐ Most Popular, 24/7), Library (300m away), Student Center (Public). Bot assists with safe location suggestions.
→
Benefits: No need to build chat system. Users already familiar with Messenger. Rich features (voice, video, location sharing) built-in. Privacy handled by Messenger. Saves development time. Only approved finders see messenger button.

Hero remains functional Search, filters, and navigation all work offline. Subtitle shows "Browsing locally · 32 items cached" to indicate offline mode.

4
Pending changes list Shows all changes waiting to sync: new items 📤, status updates ✏️, tips 💬. Each has ⏳ pending indicator. Retry connection button at top. When online, WorkManager auto-syncs all pending changes.
Room SSOT Pattern
→
Room database is the Single Source of Truth. UI reads from Room via Flow. Changes write to Room immediately (instant UI update), then WorkManager syncs to cloud in background. App is fully functional offline.
